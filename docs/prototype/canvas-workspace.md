# 画布交互纸面原型（Sprint 0 产出）

对应计划书 Sprint 0「画布交互纸面原型」任务。Sprint 1 按此文实现骨架 UI。

## 1. 工作区布局

```text
┌──────────────────────────────────────────────────────────────┐
│ Toolbar：Logo | 导入图片 | 模板切换(A/B/C/D) | 撤销 重做 | 导出PNG │
├──────────────┬──────────────────────────────┬────────────────┤
│ TemplatePanel│        CanvasStage           │ InspectorPanel │
│  模板列表     │   ┌────────────────────┐     │  参数控件列表    │
│  (缩略图+名称)│   │   画布（预览渲染）    │     │  · 滑块/下拉/色板│
│  当前模板高亮 │   │   contain 适配居中   │     │  · 名称+当前值   │
│              │   └────────────────────┘     │  · 重置默认值    │
│ AssetPanel   │                              │                │
│  素材分类/搜索│                              │                │
│  (P1：可折叠) │                              │                │
└──────────────┴──────────────────────────────┴────────────────┘
```

- **CanvasStage**：预览画布按视口缩放（contain），原图像素坐标 → 画布坐标换算集中在一处工具函数。
- **InspectorPanel**：按当前模板 schema 自动渲染参数控件；控件显示名称与当前值（NFR-08）。
- 未导入图片时 CanvasStage 显示拖拽导入引导区（支持点击选择 + 拖放）。

## 2. 核心交互流

| 操作      | 行为                                       | 异常/降级                         |
| --------- | ------------------------------------------ | --------------------------------- |
| 导入      | 文件选择/拖放 → 校验格式尺寸 → 解码        | 失败显示可读原因，保持原状态      |
| 切模板    | 加载该模板默认参数 → 重渲染预览            | 分析未完成时用默认色/无检测框模式 |
| 调参数    | 滑块变化 → rAF 合并 → 重渲染（不重复分析） | 无                                |
| 重新随机  | 更新 seed → 重渲染                         | seed 记入历史事务                 |
| 撤销/重做 | HistoryManager 恢复 before/after（P1）     | 按钮置灰                          |
| 导出      | 目标尺寸独立重绘 → toBlob → 下载           | 超尺寸提示，失败可重试            |

## 3. 坐标换算约定

- 原图像素坐标为唯一事实来源；预览画布维护 `scale/offsetX/offsetY`。
- 正向：`canvasX = imageX * scale + offsetX`；反向用于拖拽框（Digital 1 手动框选）。
- 检测框、波点区域、素材位置全部以原图坐标存储，渲染时统一换算。

## 4. 状态分区（对齐计划书 6.3）

- 组件内：面板折叠、选中项、弹窗。
- Zustand（可序列化）：项目状态、模板参数、seed、历史栈。
- 资源仓库（ID 引用）：位图、Blob、模型实例。
