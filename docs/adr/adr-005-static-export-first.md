# ADR-005：静态导出优先，动态视频暂缓

- **状态**：已接受（Sprint 0，2026-10-14）
- **背景**：动态雪花/视频导出（P2）依赖逐帧渲染与视频编码，开发成本高；课程周期内静态导出更易保证质量与可测性。
- **决策**：验收只覆盖静态 PNG 导出；导出用目标尺寸独立 Canvas 重绘 + `toBlob()`，不直接放大预览图；动态视频仅在 P0/P1 全部完成后评估。
- **原因**：先保证核心闭环质量（计划书 2.3）；预览与导出尺寸分离避免缩放损失（NFR-02）。
- **重新评估条件**：P0/P1 提前完成且时间富余时，可做短时预览动画，但不纳入静态导出验收。
