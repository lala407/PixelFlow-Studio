# ADR-004：IndexedDB（Dexie）保存项目与素材

- **状态**：已接受（Sprint 0，2026-10-14）
- **背景**：需保存项目 JSON、用户素材 Blob 与历史快照；localStorage 容量小（约 5MB）且只能存字符串。
- **决策**：使用 IndexedDB，通过 Dexie 封装并管理 schema 版本升级；大对象（位图/Blob）以资源引用（ID）方式存储，不进入普通 UI 状态。
- **原因**：容量大、支持 Blob 与索引；Dexie 提供类型友好的事务与版本迁移（计划书附录 A）。
- **重新评估条件**：需要多设备同步或多人协作时引入后端（见 ADR-001）。
