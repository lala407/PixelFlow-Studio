# ADR-003：统一 AnalysisResult 共享分析结果

- **状态**：已接受（Sprint 0，2026-10-14）
- **背景**：四个模板都需要主色/尺寸/人脸框等数据；各自重复分析会导致重复计算、结果不一致与维护困难。
- **决策**：定义统一 `AnalysisResult`（含 capabilities 能力描述，字段允许部分缺失），分析一次、四模板消费；检测坐标一律为原图像素。
- **原因**：避免重复昂贵分析；模板与分析解耦（NFR-06）；能力缺失可降级而非报错（计划书 6.2）。
- **重新评估条件**：新增分析能力时向后兼容扩展字段；若某模板需要独有分析，作为独立能力项挂载，不破坏现有契约。
