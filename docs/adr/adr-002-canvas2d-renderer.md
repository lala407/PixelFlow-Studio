# ADR-002：Canvas 2D 作为主渲染器

- **状态**：已接受（Sprint 0，2026-10-14）
- **背景**：核心功能为拼接、遮罩、波点绘制、Glitch、拼贴与 PNG 导出；备选方案有 WebGL/Shader 与纯 DOM。
- **决策**：使用 Canvas 2D API 作为唯一渲染路径；预览与导出共享同一绘制函数。
- **原因**：学习成本低、API 成熟（像素读取/clip/mask/toBlob 全覆盖）；技术验证 Demo 1/2 已确认绘制与导出链路可用。
- **重新评估条件**：性能测试证明 Canvas 2D 无法满足某复杂效果的实时预览时，仅对该效果引入 WebGL。
